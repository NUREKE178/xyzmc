# XYZ — лендинг Minecraft-сервера

Чистый HTML/CSS/JS, без сборки и зависимостей. Откройте `index.html` или выложите папку на любой хостинг (Nginx, GitHub Pages, Netlify).
Локально: `python3 -m http.server 8000`.

## Файлы
| Файл | Назначение |
|---|---|
| `index.html` | Каркас, SEO и Open Graph теги |
| `js/config.js` | **Все ссылки, IP и тексты** — правьте только его |
| `js/main.js` | Отрисовка секций из конфига, онлайн (mcsrvstat), копирование IP, карусель, меню, анимации |
| `css/style.css`, `css/fonts.css` | Стили и шрифты; цвета/размеры — в `:root` |
| `assets/` | Картинки (сейчас — заглушки) |

## Где заменить картинки (с тем же именем, или поменяйте путь в `config.js`)
- `assets/logo.png` — логотип (шапка, hero, подвал, apple-touch-icon), квадрат с прозрачным фоном
- `assets/favicon.png` — иконка вкладки (64×64)
- `assets/hero.jpg` — арт главного баннера, 1920×1080+
- `assets/mode-xyz.jpg` — картинка режима (16:9)
- `assets/news-1.jpg … news-4.jpg` — новости (16:9)
- `assets/og.jpg` — превью для соцсетей, 1200×630

## Дизайн
«Кристальный» стиль под логотип: срезанные углы у карточек и кнопок, неоновые фиолетовые лучи и сетка в hero, бегущая лента, свет за курсором, огромный контурный XYZ в футере.
Цвета (фиолетовый, розовый акцент, тёмно-синий фон) и размер среза углов (`--cut`) — переменные в `:root` файла `css/style.css`. Оранжевых и жёлтых цветов нет.
Шрифты Unbounded и Onest лежат в `assets/fonts/` (подключены в `css/fonts.css`), внешних запросов за шрифтами нет.
Строка над заголовком hero — `hero.version`, бегущая лента — `ticker` в `config.js`.

## Как добавлять
- **Режим:** скопируйте объект в `modes.items` в `config.js`, укажите `image`, `name`, `text`, `ip`.
- **Новость:** добавьте объект в `news.items` (`title`, `text`, `date` в формате `ГГГГ-ММ-ДД`, `image`, `href`); кнопка «Больше новостей» — `news.moreLabel` / `news.moreHref`.
- **Вопрос FAQ / преимущество:** добавьте элемент в `faq.items` / `features.items`.
- Слово в `{фигурных скобках}` в заголовке подсвечивается фиолетовым градиентом.

## Перед публикацией
Поменяйте домен `https://xyzmc.su/` в `index.html` (canonical, `og:url`, `og:image`) на реальный.
