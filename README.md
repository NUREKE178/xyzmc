# XYZ — сайт Minecraft-сервера

Статичный многостраничный сайт на HTML/CSS/JS: без сборки и зависимостей. Выложите папку на любой хостинг (Nginx, GitHub Pages, Netlify) или откройте `index.html`.
Локально: `python3 -m http.server 8000`.

## Страницы
| Файл | Что на странице |
|---|---|
| `index.html` | Главная: hero с кнопкой «Играть сейчас», новости (слайдер), баннеры «Магазин / Discord / Telegram» |
| `play.html` | Играть: «Почему XYZ», «Режимы сервера», «Как начать играть» |
| `team.html` | Команда: карточки со скинами по нику |
| `faq.html` | Вопросы и ответы + баннеры Discord / Telegram |

Кнопка «Скопировать IP» в шапке копирует адрес сервера на любой странице.

## Файлы
| Файл | Назначение |
|---|---|
| `js/config.js` | **Все ссылки, IP, тексты, команда, новости, баннеры** — правьте только его |
| `js/core.js` | Общее: шапка, подвал, чат, копирование IP, шаблоны блоков |
| `js/pages/*.js` | Отрисовка конкретной страницы (`home`, `play`, `team`, `faq`) |
| `css/style.css`, `css/fonts.css` | Стили и шрифты; цвета, радиусы и отступы — в `:root` |
| `sitemap.xml`, `robots.txt` | SEO. Замените `xyzmc.su` на реальный домен |

## Где заменить картинки (с тем же именем, либо поменяйте путь в `config.js`)
- `assets/logo.png`, `assets/favicon.png` — логотип и иконка вкладки
- `assets/hero.jpg` — фон hero и шапок страниц (размывается автоматически)
- `assets/banner-shop.png`, `banner-discord.png`, `banner-telegram.png` — персонажи для баннеров. Нужен PNG с **прозрачным фоном**, персонаж в полный рост (сейчас заглушки)
- `assets/mode-xyz.jpg` — картинка режима (16:9)
- `assets/news-1.jpg … news-4.jpg` — новости (16:9)
- `assets/og.jpg` — превью для соцсетей, 1200×630
- `assets/skin-placeholder.png` — заглушка, если у участника команды нет ника

## Как редактировать
- **Команда:** `team.members` в `config.js` — `name`, `nick` (по нему подтягивается скин), `role`. Пустой `nick` — показывается заглушка. `highlight: true` выделяет роль розовым. Скины берутся с minotar.net, при сбое — с mc-heads.net (адреса в `team.skinUrl` и `team.skinFallbackUrl`).
- **Баннеры:** `banners.items` — заголовок, текст, кнопка, ссылка, картинка, цвет (`violet` / `indigo` / `plum`).
- **Новость / режим / вопрос FAQ:** добавьте объект в `news.items` / `modes.items` / `faq.items`.
- **Новая страница:** скопируйте `faq.html`, поменяйте `data-page`, title, meta и подключаемый `js/pages/*.js`, добавьте пункт в `nav`.
- Слово в `{фигурных скобках}` в заголовке подсвечивается акцентным цветом.

## Перед публикацией
Замените домен `https://xyzmc.su/` в `canonical`/`og:*` во всех `.html` и в `sitemap.xml` на реальный.
