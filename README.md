# XYZ — сайт Minecraft-сервера

Статические страницы + небольшое API и админ-панель. Статика лежит в `public/`, серверный код — в `api/` и `lib/`.

## Страницы
| Файл | Что на странице |
|---|---|
| `index.html` | Главная: hero с кнопкой «Играть сейчас» (открывает окно с IP и инструкцией), последние новости, баннеры «Магазин» и «Соцсети» |
| `news.html` | Архив всех новостей (кнопка «Больше новостей») |
| `article.html?id=…` | Полный текст новости («Читать далее») |
| `rules.html` | Правила и список запрещённых модов с поиском |
| `team.html` | Команда |
| `faq.html` | Вопросы и ответы |
| `play.html` | О сервере: преимущества, режимы, как начать |
| `admin.html` | Админ-панель (закрыта паролем, не индексируется) |

## Админ-панель
`/admin.html` → вход по паролю. Разделы:
- **Новости** — публикация, редактирование и удаление (заголовок, дата, картинка, текст). На главной видны последние 4, остальные — в архиве.
- **Команда** — добавление, удаление, порядок, имя, роль, ник (для скина), загрузка своего фото.
- **Главный экран** — стандартный фон, своя картинка или видео (файл или https-ссылка).

Картинки уменьшаются в браузере перед загрузкой. Пока в админке ничего не сохранено, сайт показывает запасные данные из `public/js/config.js`.

## Запуск на Vercel
1. В проекте Vercel: **Storage → Create → Blob**, доступ **Public**, подключить к проекту (появится `BLOB_READ_WRITE_TOKEN`).
2. **Settings → Environment Variables**: `ADMIN_PASSWORD` — пароль админки, **не короче 8 символов** (без него админка выключена). Необязательно: `SESSION_SECRET` — случайная строка для подписи сессий.
3. Redeploy. Конфигурация (`vercel.json`) сама укажет папку `public/` и маршрут `/api/*`.

Ограничение Vercel: тело запроса функции ≈ 4,5 МБ, поэтому видео для фона можно загрузить файлом до 4 МБ; более тяжёлое — вставьте прямую https-ссылку.

## Локальный запуск / свой сервер
```
npm install
ADMIN_PASSWORD=ваш-пароль npm start      # http://localhost:8787
npm test                                  # проверки API
```
Данные хранятся в `data/` (в git не попадают). Для VPS задайте `PORT`, `DATA_DIR`, `MAX_VIDEO_MB`.

## Безопасность админки
Пароль только в переменной окружения; сессия — подписанная HttpOnly-cookie (`SameSite=Strict`, 12 часов); запросы-изменения принимаются только со своего origin и с заголовком `x-requested-with`; ограничение попыток входа; на загрузку допускаются только JPG/PNG/WebP/GIF/MP4/WebM (проверка по содержимому, не по расширению); весь текст на страницах экранируется.

## Файлы
| Путь | Назначение |
|---|---|
| `public/js/config.js` | Ссылки, IP, тексты, правила, список модов, запасные новости и команда |
| `public/js/core.js` | Общее: шапка, подвал, окно «Играть», копирование IP, загрузка контента, анимации |
| `public/js/pages/*.js` | Отрисовка страниц |
| `public/js/admin.js`, `public/css/admin.css` | Админ-панель |
| `public/css/style.css`, `fonts.css` | Стили и шрифты (токены в `:root`) |
| `lib/`, `api/index.js`, `server.js` | API, хранилище (Vercel Blob или файлы), локальный сервер |
| `test/` | Автотесты API |
